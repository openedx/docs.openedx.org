Open the Competency Management and Taxonomy Editing Pages
#########################################################

.. tags:: educator, how-to

A Competency taxonomy has two separate workflows in Studio, and each workflow
has its own page. This guide describes when to use each page and how to open
it.

Choose the Page for the Task
****************************

The two pages offer different options, choose the page that matches the
task before starting.

.. list-table::
   :header-rows: 1
   :widths: 20 40 40

   * - Page
     - Use this page to
     - How to open it
   * - Taxonomy editing page
     - Add, rename, nest, or delete the competencies in the taxonomy. This page
       changes the taxonomy itself.
     - Click the taxonomy card.
   * - Competency Management page
     - Work with competency criteria, which connect each competency to graded
       course content. This page does not change the competencies in the
       taxonomy.
     - Select :guilabel:`Apply Competencies`.

Tags taxonomies have only the taxonomy editing page. :guilabel:`Apply
Competencies` appears only for Competency taxonomies. For how a taxonomy
becomes a Competency taxonomy, see :ref:`about-competency-taxonomies`.

Open the Competency Management Page
***********************************

#. From Studio Home, select the **Taxonomies** tab.

#. Select a Competency taxonomy to work with. A target icon to the left of the
   taxonomy name indicates a Competency taxonomy.

#. Open the Competency Management page in one of the following ways.

   * Select the :guilabel:`Apply Competencies` button at the bottom of the
     taxonomy card.
   * Select the three-dot menu on the taxonomy card, then select
     :guilabel:`Apply Competencies`.

   .. image:: /_images/educator_how_tos/taxonomies_apply_competencies_entry_points.png
      :alt: A screenshot of a Competency taxonomy card with its three-dot
            menu open, showing Apply Competencies as the last menu item, and
            the Apply Competencies button at the bottom of the card.

The Competency Management page opens for that taxonomy. The page title is the
taxonomy name, and the **Taxonomies** link at the top of the page leads back to
the **Taxonomies** page.

The left side of the page lists the taxonomy's competencies as a tree. Select
:guilabel:`Expand All` or :guilabel:`Collapse All` to show or hide every level
of the tree. When a competency is selected, the right side of the page shows
the competency criteria associations for that competency, and a list of courses
that can be searched and filtered by start date.

.. image:: /_images/educator_how_tos/taxonomies_competency_management_page.png
   :alt: A screenshot of the Competency Management page, showing the
         Taxonomies link and taxonomy name at the top, the competency tree on
         the left, and the course list on the right for the selected
         competency.

.. note::

   The Competency Management page can also be opened from the taxonomy editing
   page. Select :guilabel:`Actions`, then select :guilabel:`Apply Competencies`.

If :guilabel:`Apply Competencies` does not appear, either the taxonomy is a Tags
taxonomy, not a Competency taxonomy, or the current user does not have
permission to apply that taxonomy to content. Contact an organization or
instance administrator.

Open the Taxonomy Editing Page
******************************

#. From Studio Home, select the **Taxonomies** tab.

#. Click anywhere on the taxonomy card except the three-dot menu and the
   :guilabel:`Apply Competencies` button.

The taxonomy editing page opens. This page works the same way for every
taxonomy type. For how to use it, see :ref:`manage-taxonomy-tags`.
